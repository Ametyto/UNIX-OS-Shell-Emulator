# UNIX-OS-Shell-Emulator

## 1. Общее описание

Данный проект представляет собой минимальный прототип (REPL) эмулятора языка оболочки UNIX-подобной ОС. Эмулятор выполнен в виде графического интерфейса (GUI) с использованием библиотеки **Eel (Python + HTML/CSS/JS)**.

Заголовок окна формируется динамически на основе текущего имени пользователя и имени хоста системы (`username@hostname`).

### Структура проекта

```text

│   ├── icon.ico

```

## 2. Описание всех функций и настроек

### Backend (`app.py`)
* **`get_user()`** (`@eel.expose`): Возвращает строку формата `username@hostname`, сформированную из реальных данных ОС через модули `getpass` и `platform`.
* **`replace_vars(args)`**: Функция-парсер. Находит в переданном аргументе переменные окружения, начинающиеся с символа `$`, и подставляет их текущие значения (например, `$HOME`). Если переменная не найдена в словаре `variables`, возвращает служебную ошибку `__ERR_VARS__`.
* **`process_command(cmd: str)`** (`@eel.expose`): Основной обработчик команд от пользователя:
  * Парсит имя команды и её аргументы.
  * Выполняет замену переменных через `replace_vars`.
  * Обрабатывает логику встроенных команд и команд-заглушек (`ls`, `cd`).
  * Возвращает текстовый результат вывода или служебный флаг `__EXIT__` для закрытия приложения.

### Frontend (`script.js` / `index.html` / `style.css`)
* **Инициализация**: При загрузке страницы делает асинхронный вызов `eel.get_user()` и устанавливает заголовок окна в формате `Эмулятор — [username@hostname]`, а также обновляет приглашение к вводу (prompt) `username@hostname:~$ `.
* **Обработка ввода**: Слушает нажатие клавиши `Enter`, передает строку в Python через `eel.process_command()`, выводит ответ в терминал и выполняет автоскролл вниз.
* **Защита интерфейса GUI**: 
  * Отключено контекстное меню (ПКМ).
  * Заблокированы клавиши перезагрузки страницы (F5, Ctrl+R) и вызова инструментов разработчика (F12, Ctrl+Shift+I/J) для предотвращения сбоя сессии эмулятора.
  * Установлен постоянный фокус на инпут при клике в любую область окна.

### Конфигурация и переменные (`commands.json` / `variables`)
* **`commands.json`**: Файл конфигурации в формате JSON, содержащий справку и описание доступных команд терминала.
* **Словарь `variables`**: Содержит сопоставление переменных окружения и их значений. По умолчанию считывает системную переменную `$HOME` (`USERPROFILE` в Windows).

## 4. Примеры использования

Ниже приведены примеры выполнения встроенных команд и обработки ошибок в интерактивном режиме.

### 1. Вызов справки (`help`)
```text
user@shell:~$ help
Доступные команды: help, echo, cd, ls, exit
```
```text
user@shell:~$ help exit
Команда exit закрывает консоль. Аргументы не предполагаются.
```

### 2. Подстановка переменных окружения (`$HOME`)
```text
user@shell:~$ echo $HOME
echo C:\Users\Username
```

### 3. Работа команд-заглушек (`ls`, `cd`)
```text
user@shell:~$ ls -la /usr/bin
Команда: ls, аргументы: -la /usr/bin
```
```text
user@shell:~$ cd documents
Команда: cd, аргументы: documents
```

### 4. Обработка ошибок
* **Несуществующая переменная окружения:**
  ```text
  user@shell:~$ echo $UNKNOWN_VAR
  Ошибка. Переменной не существует.
  ```
* **Ввод несуществующей команды:**
  ```text
  user@shell:~$ clear
  Несуществующая команда: clear
  ```
* **Передача невалидных аргументов:**
  ```text
  user@shell:~$ exit 123
  Команда exit не принимает аргументов.
  ```

### 5. Завершение работы (`exit`)
При вводе команды `exit` без аргументов окно графического эмулятора автоматически закрывается.
```text
user@shell:~$ exit
```
